# Islio 🏝️

**Independent islands. One seamless experience.**

Islio is a lightweight, framework-agnostic JavaScript/TypeScript
library designed to simplify microfrontend architecture.

Inspired by the concept of islands architecture, Islio helps
developers build and compose independent frontend applications
into a unified experience without being tied to a specific
framework.

Whether you're using React, Vue, Angular, or vanilla JavaScript,
Islio aims to make microfrontend composition simple, flexible,
and scalable.
